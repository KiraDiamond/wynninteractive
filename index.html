Welcome

              
Wynnteractive Map

            

          

          
        

        

          Wynnteractive Map is an interactive Wynncraft map that brings quests, discoveries, caves, raids, boss altars,
          profession spots, travel routes, lootrun camps, and mob locations into one place.
        

        

          

            
What It Does

            
    
              
  • Search and filter the world by marker type.
    • 
              
  • Open guide notes, linked videos, and reference images per marker.
    • 
              
  • Track found markers locally in your browser.
